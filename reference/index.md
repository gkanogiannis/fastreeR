# Package index

## VCF

Functions operating on VCF files

- [`vcf2dist()`](https://gkanogiannis.github.io/fastreeR/reference/vcf2dist.md)
  : Calculate distances between samples of a VCF file
- [`vcf2tree()`](https://gkanogiannis.github.io/fastreeR/reference/vcf2tree.md)
  : Generate phylogenetic tree from samples of a VCF file
- [`vcf2istats()`](https://gkanogiannis.github.io/fastreeR/reference/vcf2istats.md)
  : Calculate various per sample statistics from a VCF file
- [`vcf2clusters()`](https://gkanogiannis.github.io/fastreeR/reference/vcf2clusters.md)
  : Perform Hierarchical Clustering and tree pruning on samples of VCF
  file

## FASTA

Functions operating on FASTA sequences

- [`fasta2dist()`](https://gkanogiannis.github.io/fastreeR/reference/fasta2dist.md)
  : Calculate distances between sequences of a FASTA file

## Distance and tree utilities

- [`dist2tree()`](https://gkanogiannis.github.io/fastreeR/reference/dist2tree.md)
  : Generate phylogenetic tree from samples of a distance matrix
- [`dist2clusters()`](https://gkanogiannis.github.io/fastreeR/reference/dist2clusters.md)
  : Perform Hierarchical Clustering and tree pruning on a distance
  matrix
- [`tree2clusters()`](https://gkanogiannis.github.io/fastreeR/reference/tree2clusters.md)
  : Perform Hierarchical Clustering and tree pruning on a phylogenetic
  tree
